# Budget Buckets

A mobile-first monthly budgeting web app for household use. Built as a Progressive Web App (PWA) so it installs on iPhone like a native app.

## What it does

- Displays monthly budget categories as visual "buckets" with progress bars (green → yellow → red)
- Lets family members enter and manage transactions against each category
- Imports monthly budget setup from a Google Sheets CSV export
- Syncs in real time across all family devices

## Tech Stack

| Layer | Tool |
|---|---|
| Frontend | React + Vite + Tailwind CSS |
| Database | Firebase Firestore |
| Auth | Firebase Authentication |
| Hosting | Netlify |
| Mobile | PWA (installable on iPhone via Safari) |
